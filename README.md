 **Ultrasonic Detection System**

**Description**

**Developed an Arduino-based ultrasonic detection system using an HC-SR04 ultrasonic sensor and a servo motor.**

**The system detects the distance of an object and controls the servo motor according to the programmed distance.**

**Procedure**

**Connect the HC-SR04 ultrasonic sensor to the Arduino Uno.**

**Connect the servo motor to the Arduino using jumper wires.**

**Place the required components on the breadboard and make the circuit connections.**

**Connect the Arduino Uno to the computer using a USB cable.**

**Upload the ultrasonic distance and servo control program to the Arduino.**

**Place an object in front of the ultrasonic sensor and observe the servo motor response.**

**Working**

**The HC-SR04 ultrasonic sensor sends ultrasonic waves toward an object.**

**The reflected waves are received by the sensor as an echo.**

**The Arduino calculates the distance based on the time taken for the echo to return.**

**When the object reaches the programmed distance, the Arduino sends a control signal to the servo motor.**

**The servo motor rotates to the required position based on the detected distance.**
